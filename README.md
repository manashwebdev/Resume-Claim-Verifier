# Resume Claim Verifier
"Don't just claim skills. Prove them."

## Run
```
cd backend  && npm i && npm start        # http://localhost:4000  (optional: GITHUB_TOKEN=xxx for higher rate limits)
cd frontend && npm i && npm run dev      # http://localhost:3000  (set NEXT_PUBLIC_API_URL for deployed backend)
```
Deploy: frontend -> Vercel, backend -> Render (start command `npm start`).
Not included yet: evidence timeline view, modals/tabs, Gemini layer, magnetic buttons.
